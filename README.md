# Skornet — Connecting the HVAC Service Ecosystem

A modern, responsive, high-performance landing page for **Skornet** designed to connect service demand, business operations, field activities, and customer service delivery across the HVAC ecosystem.

## Primary Objective
Streamline and facilitate HVAC technician onboarding through integrated Google Form registration with verified identity, certifications, and operational coverage.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Asset Optimization**: Sharp (WebP compression & responsive image sizing)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
Generates the production bundle in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
