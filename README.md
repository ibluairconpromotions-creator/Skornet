# SKORNET — Connecting the HVAC Service Ecosystem

**One Platform for Every Technician, Service Call and Business Operation.**

Brand Message: **Connect • Verify • Manage • Grow**

Official Website: [https://skornet.in/](https://skornet.in/)

## Project Overview
SKORNET is a digital platform designed to connect the HVAC service ecosystem. It brings HVAC service businesses, field technicians, administrators, and customer-facing workflows into one structured digital environment.

From technician verification (KYC) and service-call assignment to attendance tracking (GPS) and digital work history, SKORNET organizes the information and workflows behind HVAC service delivery.

## Key Capabilities
- **Technician KYC & Verification**: Aadhaar identity check, skill matrix, and professional experience validation.
- **Workforce Management**: Centralized technician directory with organizational isolation.
- **Service-Call Assignment**: Systematic dispatch with real-time status tracking.
- **Owner & Admin Dashboards**: Complete operational visibility into active calls, attendance, and approvals.
- **Technician Mobile Application**: Mobile workflow for assigned calls, appointments, and attendance.
- **GPS-Based Attendance**: Device-validated daily check-ins and travel distance logging.
- **Overtime & Expenses**: Review workflows for fuel allowance, on-site expenses, overtime, and incentives.
- **Digital Work History**: Audit trail of completed equipment services and diagnostic records.

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Asset Optimization**: Sharp (WebP compression & responsive image sizing)
- **Deployment**: Vercel
